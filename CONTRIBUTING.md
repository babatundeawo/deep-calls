# Contributing

Thank you for reading closely.

**Found a mistake or have a question to explore?** [Open an issue](https://github.com/babatundeawo/deep-calls/issues/new/choose) and name the essay and passage.

**Want to fix something yourself?** Edit the file in `content/` on GitHub (the pencil icon) and propose the change. A preview of the built site is attached to every pull request under Checks, then Artifacts.

## Running it on your computer (optional)

```bash
pip install -r requirements.txt
python scripts/build.py
python scripts/check.py
```

The finished site appears in `dist/`; open `dist/index.html` in a browser.

Essay text remains the author's work; by proposing a change you agree it may be used in the essay.

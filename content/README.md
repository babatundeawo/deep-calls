# Essays

**To publish an essay, put one `.md` file in this folder and commit it. That is all.** GitHub rebuilds and republishes the site by itself within about two minutes. No other file needs to change.

- The file name becomes the web address: `the-god-who-draws-in-curves.md` is published at `/writeups/the-god-who-draws-in-curves.html`. Capital letters, spaces and underscores in the name are tidied automatically.
- A details block at the top is **optional**. Without one, the title is taken from the first `# Heading`, the category is chosen from the wording, and the date is the day the file was added.
- To control the details yourself, start the file with a block between two `---` lines (title, subtitle, category, topics, verse, verse_ref, featured, date, summary). The full list is in [docs/CUSTOMISING.md](../docs/CUSTOMISING.md).
- A file whose name starts with `_` (for example `_draft.md`) is ignored, so you can keep unfinished work here.
- If a file cannot be published (for example it is empty), the other essays still go live. The run in the **Actions** tab shows a yellow warning naming the file and the reason.

## Essay standards

Every essay here follows the same house rules, so the library reads as one voice.

* No em dashes, en dashes or hyphens in the body. Write number ranges as "Romans 8:1 to 4". The only exceptions are the dash in a block quote attribution line (`> — Romans 8:1 (ESV)`) and the hyphens APA needs inside URLs and DOIs in References.
* British spelling, no bullet lists in the body, and `***` for section dividers. Where a list is unavoidable, use `*` markers.
* Headings are plain phrases of four to eight words, with no colons or slogans.
* Scripture is quoted in one translation per quotation and named. Other quotations are used only when they were checked against a source.
* No indigenous language phrases or proverbs. Names of people and places are fine.
* Constructed scenes are labelled as scenes, and nothing is presented as invented personal memory.
* Give each essay one `category` and two or three comma separated `topics` (for example `topics: Providence, Waiting`), reusing existing topics where they fit.
* The details block should carry a short plain `subtitle`, and the `title` should stay under ten words with no colon.
* Each essay ends with a References section: Biblical references first, then other sources in one alphabetical APA 7 list, then any Translation Notices.

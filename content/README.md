# Essays

Every file here ending in `.md` becomes one essay on the site. The file name becomes the web address, so `the-god-who-draws-in-curves.md` is published at `/writeups/grace-and-works.html`.

Each essay starts with a short block of details between two `---` lines (title, subtitle, category, verse, verse reference), followed by the essay text in Markdown. The full list of options is in [docs/CUSTOMIZING.md](../docs/CUSTOMIZING.md).

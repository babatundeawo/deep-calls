# Review notes

One notes file per essay, written when the essays were rewritten in full from the original uploads. They are working papers, not published pages, and the site build ignores this folder.

Each file lists what was restored from the original, what was added, any facts corrected or dropped, and the verification flags. Read the flags before an essay is treated as final. The main ones to clear are:

* Scripture quotations that could not be opened on a Bible site during research (check wording against the translation's own text).
* Quotations and sources carried over from earlier drafts and not reopened.
* Translation notice wording (ESV, NIV, Saheeh International) to confirm with the publisher.

Delete a notes file once its flags are cleared, or keep it as a record.

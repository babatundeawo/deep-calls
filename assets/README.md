# Assets

Styles, scripts and fonts for the site.

- `css/` – numbered style sheets (`00-fonts.css` to `08-print.css`), joined and minified at build time. Colours and sizes live in `01-tokens.css`.
- `js/` – small scripts, one per job (theme, search, reading progress, listen mode).
- `fonts/` – self-hosted Fraunces, Literata and Inter, with their licences.

# Scripts

The site generator, written in Python.

- `build.py` – turns `content/` into the finished site in `dist/`.
- `check.py` – checks the built site for broken links, missing titles and similar problems.
- `content.py`, `templates.py`, `icons.py`, `images.py` – reading essays, page layouts, icons, and brand/social images.
- `fonts/` – font files used only to draw the social cards.
